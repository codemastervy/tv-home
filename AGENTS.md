# Instructions for an AI agent setting this up

Follow [SETUP.md](SETUP.md), part A: one question per message, wait for each answer, read the plan back and wait
for a clear yes before installing anything. Use `setup.py` for every answer. Emulator serials only (`emulator-*`)
unless the person says it is their own TV and gives its address. Never scan the network, never ask for streaming
passwords, never print or commit a TMDB key. This app contains no AI; Gemini is the TV's own assistant.
